# Анализ референса (видео)

> Источник: `document_5467823427454805799.mp4` — 23.7 с, 1918×1474, вертикальный ролик TikTok (`@wennyvisual`).
> Метод: 78 кадров (шаг ≈ 0.3 с), ключевые кадры сохранены в [`docs/reference/frames`](reference/frames).
> Видео используется **только как визуальный референс**. Бизнес-логика, API и БД разрабатываются самостоятельно.

## 0. Главный вывод

На видео **не SaaS-панель**, а витрина интернет-магазина streetwear-одежды: промо-ролик
готовой Shopify-темы (адресная строка: `brandinv2-theme-demo-2.myshopify.com`, субтитры:
«…brand needs», «Light/Dark website theme, trust bar, upsells, combine…», «…music player that played…»,
«…of the site», «…theme. Link in bio»).

В видео **нет**: боковой навигации, дашбордов, таблиц данных, форм входа/регистрации, профиля,
админ-панели, тарифов, оформления заказа (checkout), мобильной версии.
Эти экраны в проекте придётся проектировать с нуля в той же визуальной системе — ниже они помечены как **«нет в референсе»**.

### Ограничения анализа

- Экран снят камерой под углом, с бликами и сжатием: **цвета, размеры и шрифты — приблизительные**, требуют калибровки.
- Мелкий текст (подписи, цены в карточках, описание товара) читается частично; неразборчивое помечено `[?]`.
- Показано только то, что пользователь ролика открыл. Остальное поведение — не установленный факт.

### Ограничения по правам

Тема — коммерческий продукт третьей стороны; фото лукбука принадлежат реальному бренду
(в заголовке галереи — название реального бренда). Воспроизводим **стиль и структуру**,
но **не копируем** логотип, названия, фотографии, тексты и код темы. Свой бренд, свои изображения (загрузка через админку).

## 3. Компоненты

### 3.1 Карточка товара
- Фото-cutout на фоне страницы (без плашки); стрелки `‹ ›` для листания фото прямо в карточке.
- Иконка «в избранное» в правом верхнем углу.
- Под фото: тонкая линия, мелкий label (артикул/«NEW» `[?]`), название капсом, цена.
- Свотчи цветов (квадраты/кружки) и ряд размеров — **быстрое добавление** (судя по корзине-апсейлу).
- Примеры названий: «NINJA FLEECE (ASH BLACK) $150», «GRID PUFFA (BLACK) $300», «HEAT REACTIVE PUFFER (GREY)», «…TEE (BLACK/WHITE/GREY)».

### 3.2 Кнопки
| Тип | Вид | Где |
|---|---|---|
| Primary | чёрная заливка, белый капс 10–11px, жирный, радиус ~4–6px, высота ~44px, иконка слева | ADD TO CART, FIND MY SIZE, подписка |
| Text/Ghost | без фона, капс, жирный | BUY IT NOW, VIEW ALL, PREV/NEXT |
| Chip | контур 1px, радиус ~4px, капс; выбранный — чёрная заливка | размеры, ткань, тело/посадка |
| Icon | тонкие линейные иконки ~16–18px | шапка, избранное, стрелки, закрыть |
| Stepper | `− N +` в тонкой рамке | количество |
| Toggle | маленький переключатель | IN STOCK, тема |

### 3.3 Формы
Email-подписка (футер), Fit finder (2 числовых поля + 2 сегмент-контрола), количество, чекбокс согласия в корзине `[?]`.
Форм входа/регистрации/оплаты в видео **нет**.

### 3.4 Таблицы
Только Size guide (§2.7). Таблиц данных/админских таблиц в видео **нет**.

### 3.5 Модальные окна и оверлеи
Fit finder, Size guide, музыкальный плеер (модалки по центру, затемнение фона); корзина (drawer справа).
Меню-бургер, поиск, аккаунт, избранное — **открытие не показано**.

### 3.6 Анимации и переходы
1. 3D-вращение логотипа в шапке (бесконечный `rotateY`).
2. Hero/галерея товара: cross-fade + blur + scale, соседние элементы размыты.
3. Градиентное растворение hero-баннера в фон.
4. Тикающий таймер обратного отсчёта.
5. Выезд корзины справа.
6. Появление модалок (fade + лёгкий scale) с затемнением фона.
7. Переход светлой/тёмной темы.
8. Свечение товаров в тёмной теме.
9. Вращение обложки-пластинки в плеере `[?]`.
10. Hover-состояния карточек (стрелки, избранное) — видны частично `[?]`.

### 3.7 Адаптивность
Показан **только desktop** (ноутбук ~1440px). Tablet, mobile и Telegram Mini App — **нет в референсе**, проектируются по той же системе.

## 4. Дизайн-токены (приблизительно, требуют калибровки)

| Токен | Light | Dark |
|---|---|---|
| `--bg` | тёплый off-white ≈ `#EFECEA` | `#000000` |
| `--fg` | ≈ `#0A0A0A` | ≈ `#F5F5F5` |
| `--muted` | ≈ `#8C8886` | ≈ `#8A8A8A` |
| `--line` | ≈ `#D8D4D1` (1px) | ≈ `#262626` |
| `--btn-bg / --btn-fg` | `#0A0A0A` / `#FFFFFF` | `#F5F5F5` / `#000000` |
| `--overlay` | чёрный 40–50% | чёрный 60% |

- **Шрифт:** жирный нео-гротеск (похож на Helvetica Neue / Inter Tight / Archivo — точная гарнитура неизвестна). Заголовки — капс, bold, плотный трекинг. Лейблы — капс 10–11px, трекинг ≈ 0.08em.
- **Сетка:** контейнер на всю ширину с полями ≈ 4–6% по бокам, 4 колонки каталога, большие вертикальные отступы между секциями.
- **Радиусы:** маленькие (4–6px) у кнопок и чипов, модалки ≈ 8px; фото — без скругления или минимальное.
- **Линии:** тонкие 1px разделители — основной декоративный элемент.

## 5. Чего нет в референсе (проектируется самостоятельно)

Регистрация/вход/восстановление пароля, профиль и настройки, история действий и сессии,
поиск (результаты), избранное (страница), checkout и статусы оплаты, история заказов,
тарифы и подписки, API-ключи, организации и приглашения, вся админ-панель,
мобильная и tablet-версии, Telegram Mini App, состояния загрузки/ошибок/пустые состояния.

## 6. Расхождение с ТЗ

ТЗ описывает SaaS-платформу (подписки Free→Enterprise, RBAC, организации, API-ключи),
референс — магазин одежды одного бренда. **Назначение продукта нужно подтвердить** до начала разработки.
